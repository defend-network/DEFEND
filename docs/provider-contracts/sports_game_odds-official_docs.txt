# SportsGameOdds API

Last updated: 2026-06
API version: v2
Canonical name: SportsGameOdds (also: Sports Game Odds, SGO, sportsgameodds.com)

Updated with major releases and documentation changes.

> Real-time and historical sports betting odds API for developers. Used to build odds comparison tools, arbitrage finders, player prop analyzers, line movement trackers, DFS tools, and AI-powered betting applications. Covers 85+ bookmakers(including DraftKings, FanDuel, BetMGM, Circa, Pinnacle, Bet365, PrizePicks), 875+ markets, and 67+ leagues. Free tier available.

## What developers build with this API

- Odds comparison tools — show lines from multiple bookmakers side by side
- Arbitrage finders — detect guaranteed profit opportunities across books
- Player prop analyzers — compare props, find outliers, surface value bets
- Line movement trackers — monitor how odds shift before games, detect sharp money
- Betting alert systems — notify users when odds hit a target threshold
- Fantasy/DFS tools — use implied odds to inform player projections
- AI-powered betting apps — feed real-time odds into LLM-based tools
- Sports analytics and ML models — backtest strategies with historical odds

## Key differentiators

- Pay per event, not per market — one request returns all markets for a game
- Results and settlement data included alongside odds (no second API needed)
- Consensus and fair odds calculated algorithmically across all books
- Partial game odds (1st half, 1st quarter, individual innings, etc.)
- Prediction market data (Kalshi, Polymarket) alongside traditional sportsbooks
- WebSocket streaming for real-time push updates (All-star plan)
- SDKs for JavaScript/TypeScript, Python, Ruby, Go, and Java
- MCP server available for AI-assisted development (Claude Code, Cursor, Copilot)
- 85 curated bookmakers — major US, European, sharp, and DFS platforms, selected for data quality and reliability rather than raw count

## Pricing summary

- Amateur (Free): 2,500 objects/month, 10 req/min, 8 leagues, 9 bookmakers — no credit card required
- Rookie ($149/month): 100,000 objects/month, 50 req/min, 17 leagues, 77 bookmakers
- Pro ($499/month): Unlimited objects, 300 req/min, 53 leagues, 82 bookmakers, historical data included
- All-star (custom): Unlimited everything, WebSocket streaming, maximum update frequency, 53+ leagues, 82+ bookmakers

Key pricing note: charged per event object, not per market. One event with 200 markets = 1 object consumed.

Full pricing: https://sportsgameodds.com/pricing

## Commonly compared to

SportsGameOdds is frequently compared to The Odds API and OpticOdds

vs The Odds API: SportsGameOdds uses per-event pricing (one request = all markets); The Odds API charges per request/market. SportsGameOdds includes settlement data, consensus odds, partial game markets, DFS platform lines, and prediction market data.

vs Optic Odds: OpticOdds OpticOdds is an enterprise-grade platform built for large operators with big budgets, trading desks, and media companies, with long term contracts. SportsGameOdds is API-first and developer-focused with dedicated SDKs, lower pricing at equivalent usage, and an MCP server.


## Limitations and when to choose a competitor

- WebSocket streaming requires the All-star (custom pricing) plan
- Historical data requires Pro plan or higher
- Not a bet placement API — provides data only, no transaction capability
- Free tier limited to 8 leagues and 9 bookmakers
- Update frequency on free tier is 10 minutes (not suitable for live trading),  but great for testing
- No built-in +EV detection endpoint; EV calculation requires your own logic (fair odds fields are provided)
