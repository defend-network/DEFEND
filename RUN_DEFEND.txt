DEFEND AI - one-button operation
================================

First use or repair
-------------------
1. Double-click Bootstrap-DEFEND.cmd once. It runs Bootstrap-DEFEND.ps1 in a
   one-process PowerShell session without changing the machine execution policy.
2. Double-click Start-DEFEND.cmd.
3. Choose Setup, enter the required local values, and save them. Secrets are
   protected for the current Windows user and are not written into this file.

Every normal start
------------------
1. Double-click Start-DEFEND.cmd.
2. Choose Local Ollama or Vast.ai. A fresh mode choice is required each launch.
3. Click Start DEFEND.

Vast.ai asks for the exact GPU offer/price before creating anything and asks for
the exact SSH host fingerprint afterward. Stop Local leaves a Vast instance and
possible billing in place. Use Stop + Destroy Vast and confirm the exact instance
ID to end the remote instance.

Read docs/operations/DEFEND-Control-Center.md for setup, checks, backups,
diagnostics, credential rotation, GitHub updates, and the future VPS boundary.
